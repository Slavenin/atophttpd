ATOPHTTPD HELP PAGE

Locations

  • ping: ping and  test atophttpd service.
  • help: show this help page.
  • index.html: get index.html.
  • favicon.ico: get favicon.ico.
  • js/atop.js: get atop.js.
  • css/atop.css: get css/atop.css.
  • template: get template for atop rendering. Supported argument type(required, available options: generic/memory/disk/command_line).
  • showsamp: get atop sample data. Supported argument timestamp(required, UNIX timestamp to query), lables or labels(required, available options: ALL/CPU/cpu/CPL/GPU/MEM/SWP/ZSW/PAG/PSI/LVM/MDD/DSK/NFM/NFC/NFS/NET/IFB/NUM/NUC/LLC/PRG/PRC/PRM/PRD/PRN/PRE. Select one label, e.g. labels=CPU; or multiple, e.g. labels=CPU,cpu,CPL), encoding(optional, deflate/none).
  • metrics: Prometheus gauges for per-process TCP/UDP receive and transmit bytes per atop interval second, plus sample freshness and availability. Requires atop started with -K and a compatible network collector.
  • health: HTTP 200 with "ok" when the latest sample is fresh and records process-network data; HTTP 503 otherwise. Does not render the full metrics body.
